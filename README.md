# DJsOS

A personal web-based operating system built with HTML, CSS, and JavaScript.

## Features

- **Boot Screen** — animated loading sequence
- **Welcome Screen** — personal intro with links
- **Desktop Environment** — wallpaper, app icons, draggable windows
- **Top Bar** — OS name and live clock
- **Window Management** — drag, close, open, z-index stacking
- **Notes App** — sidebar navigation with multiple notes
- **Terminal** — functional command-line with built-in commands
- **Music Player** — playlist browser with play/pause/skip controls
- **About** — system info card with live uptime counter

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, backdrop-filter, animations)
- Vanilla JavaScript (no frameworks)

## Running Locally

Open `index.html` in a browser. No build step needed.
